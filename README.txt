LIVORA v3 - cara pakai
1. Letakkan gambar di folder images/ dengan nama: gambar_1.png ... gambar_15.png (jika JPG/WEBP, ubah IMG_EXT di bagian atas script.js)
2. Untuk tampilan laptop/PC, tambahkan versi "_pc" (opsional): gambar_13_pc.png, gambar_14_pc.png, gambar_15_pc.png.
   Jika file _pc tidak ada, laptop otomatis memakai versi HP.
3. Buka index.html di browser (laptop maupun HP).
Data profil/pengaturan/komoditas dashboard tersimpan otomatis di browser (localStorage).
